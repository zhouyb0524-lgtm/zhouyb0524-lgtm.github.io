03 / Work

代表项目

企业级 AI 智能助手

2026.06 – 2026.07
知识库 + OA 流程自动化 · 软件工程师
为什么做

企业内部存在大量重复的信息查询和流程操作，传统方式效率低、信息分散，因此希望通过 AI 把"知识查询"和"流程办理"统一到一个自然语言入口，尤其是高频、标准化、重复性的问题，降低员工获取信息和执行流程的成本。最终不是为了"做一个 AI 知识库"，而是为了降低企业内部的沟通和操作成本。

做了什么
  1. 需求分析与场景规划：梳理企业内部制度查询、业务咨询及 OA 审批等高频需求，分析员工在信息查找和流程执行中的核心痛点，规划"智能知识问答 + 流程引导"应用场景。
  2. 知识产品设计：完成 300+ 份企业文档的梳理与结构化处理，围绕用户实际提问方式设计知识切片、知识点及多问法扩展策略，沉淀 5000+ 知识节点，提升知识检索覆盖能力。
  3. AI方案设计与优化：基于 Coze、RAG 及 Workflow 设计知识问答与流程引导能力，结合测试问题持续优化 Prompt、检索策略及回答逻辑，提升复杂业务问题的回答质量。
  4. 流程场景落地：梳理 20+ 个高频 OA 审批场景，设计流程咨询、审批引导及节点匹配逻辑，降低员工对制度和流程的理解成本。
结果

知识覆盖率与检索命中率 ≥ 90%，平均响应 ≤ 15s，流程处理周期缩短 ≥ 30%。

AI 销售 SOP 智能陪练助手

2026.07 – 2026.08
FastAPI + React + MySQL + LLM · 软件工程师
为什么做

这个项目主要是为了解决传统销售培训中"学会了 SOP，但不会实际应用"的问题。传统培训主要依靠培训资料、统一话术和店长带教，新人缺少一个可以反复模拟真实客户的练习环境，而且销售能力也比较难量化。

所以我们设计了 AI 销售 SOP 智能陪练助手，让 AI 扮演不同类型的客户，销售人员进行真实对话。AI 根据预设的客户画像、销售 SOP 和评价标准，对销售的需求挖掘、产品介绍、异议处理和成交推进等环节进行评价，并给出改进建议。

做了什么
  1. 用户与业务场景分析：围绕销售新人培训流程，梳理价格、品质、安装、品牌对比等客户关注问题，分析销售人员在产品知识、客户需求识别及异议处理方面的核心痛点；
  2. 客户 Persona 设计：根据真实销售场景设计价格敏感型、品质关注型、安装关注型等客户画像及对话逻辑，构建 30+ 销售模拟场景，提升训练的真实性和针对性；
  3. 产品功能设计：规划销售模拟、客户角色对话、话术评价、能力反馈及产品知识查询等核心功能，设计 AI 训练流程及销售能力评估逻辑；
  4. 数据闭环设计：设计训练记录、客户画像、销售回答及评价结果的数据模型，实现销售训练过程记录和效果追踪，为后续优化训练场景提供数据基础；
  5. 产品开发落地：使用 React + FastAPI + MySQL + LLM API 完成系统开发，实现从业务需求分析、产品方案设计到 AI 应用落地的完整闭环。
结果

上线后共有 30 名销售使用，一个月内累计完成 600 次训练，覆盖 45 类客户场景；其中新人平均完成 15 次训练，重复训练率达到 60%；经过多轮训练后，销售在需求挖掘、异议处理等核心维度的平均得分从 35 提升到 85。

05 / Note

一点想法

"且视他人之疑目如盏盏鬼火，大胆去走你的夜路"

第一份工作结束后，我经历了一段比较长的职业迷茫期。纯粹的软件工程师工作并没有给我带来太多成就感。每次项目结束，我更多感受到的不是完成一件事情后的满足，而是"终于松了一口气"。离职之后，我开始认真思考：难道我真的要以这样的状态，度过职业生涯中非常重要的一段时期吗？

我不甘心。

于是，我开始主动寻找答案，大量学习和阅读，从前端到后端不断拓展自己的技术边界。恰逢 AI 开始快速发展，我也因为焦虑而接触 AI，但在这个过程中，我意外发现了自己真正感兴趣的事情——研究 AI、设计 Skills 和提示词，并通过 AI 帮助别人解决实际问题。相比单纯完成代码，我更享受的是理解一个需求、找到解决方案，并最终看到它真正产生效果的过程。

与此同时，我也曾帮助朋友运营小红书账号和视频内容。在这个过程中，我发现自己对用户需求、内容方向和市场变化有比较敏锐的感知，也能够快速发现问题并提出具有实际效果的建议。

这些经历让我逐渐意识到，也许我真正感兴趣的并不只是"把技术做出来"，而是分析和解决问题，正好是 AI 应用 / 运营 / 产品要做的事。

再结合过去工作中领导曾评价我"对需求和形势比较敏锐，很适合产品 / 运营类工作"，我开始重新认识自己的优势，也逐渐确定了下一阶段的职业方向——从单纯的软件开发，转向更偏 AI 应用、产品与业务落地的方向。

这大概就是我浅薄工作经历所有的故事，由衷感谢每一位有耐心看到这里的所有 HR、领导，本来想祝愿

"长风破浪会有时，直挂云帆济沧海"

然而过于狂傲肆意反而会让人增添惆怅，最后还是送上我最爱的这首

"竹杖芒鞋轻胜马，谁怕？一蓑烟雨任平生。"

纵有风雨，也能从容前行，自在生活。
